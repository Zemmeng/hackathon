# Unzzip · T35 · 2026-09-30 17:23

细窗（La Trobe × Swanston）以外的「矢量」底图原来只有真楼 + 真路，看着不像一张真地图。这条把它换成**真实的 OSM 矢量图**：水域、绿地、用地、铁路，从 OpenFreeMap 的 OpenMapTiles 矢量瓦片在构建期拉下来解成本地文件，网页运行时照旧只取同源文件。

**为什么这么接**（而不是运行时连瓦片服务）

- 仓库有一条硬约束：`test_web.py` 反向断言页面 `fetch()` 只能打同源 `/engine/ /roads/ /params/ /api/`，外部域名只允许 Google Fonts。[3] 的隐私理由也写在测试注释里。运行时连第三方瓦片服务会把这条断言和这条理由一起推翻。
- 构建期拉取和 `network.json` / `buildings.json` / `flows.json` 完全同一条路子：数据来源记在文件里（`tile_source`、`sources`），线上页面不出网。
- 瓦片源选 OpenFreeMap：公共实例免费、不要 key、明说「对请求数没有上限」，且官方提供整颗行星的离线下载 —— 构建期拉几块瓦片是它支持的用法。**pass 掉的**：Maptoolkit 的 Community License 明文禁止 offline tile generation / bulk extraction；MapTiler、Stadia 要 key；MapLibre 官方 demo tiles 只有国界。
- z14、6 块瓦片：CITY 层缓存是 1.6 px/页面单位（≈ 0.625 m/px），z14 的几何精度约 0.47 m/单位，够用；再高一档体积翻倍但看不出来。

另外把解码结果单独画成 PNG 肉眼核过（雅拉河、Flagstaff / Carlton / Fitzroy 花园、Flinders St 车场那一片多条股道、每条街上的电车线都对得上位置），并在 Chromium 1440×900 上按「拦截 / 不拦截 `vectormap.json`」做了 A/B：浅色和深色两套主题下，细窗外都从「一片灰格子」变成「有河、有公园、有铁路走廊、有零星小绿地」的真地图，没有回归。

**踩到的坑（值得记）**

- `python3 -m http.server 4175 -d apps/web/public` 是 README 里的「只看页面」起法，根目录里没有 `/roads/`，`vectormap.json` 和 `buildings.json` 都 404 → 页面**照设计**退回兜底层，但控制台只有一行 `console.info`。我一开始就是被这个骗了，以为没生效。这条已经写进 `apps/web/README.md`。
- 改完 `src/` 一定要 `python3 apps/web/build.py`：`test_web.py` 第 1 条就是查 `public/index.html` 与 `src/` 是否一致，不打包会红。
- MVT 的 `Layer.name/keys/values` 要按 field number 认（3/4 = length-delimited），packed 字段（`Feature.tags`、`Feature.geometry`）要先解成 varint 数组再 zigzag；面是「一次 MoveTo 起一个新环」，不是按 ClosePath 切。
